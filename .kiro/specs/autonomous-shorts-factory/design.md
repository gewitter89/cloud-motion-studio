## 2. Спецификация видеоформата

| Параметр | Значение | Обоснование |
| :--- | :--- | :--- |
| **Разрешение** | 1080 × 1920 (9:16) | Стандарт YouTube Shorts, TikTok, Instagram Reels |
| **FPS** | 30.0 | Оптимальный баланс плавности и скорости рендера |
| **Кодек видео** | `libx264`, preset `medium`, crf `20` | Высокое качество деталей текста и градиентов |
| **Цветовой диапазон**| `yuv420p` | 100% совместимость со всеми смартфонами |
| **Кодек звука** | `aac`, 256 kbps, 48000 Hz, stereo | Кристально чистая речь и глубокий бас |
| **Нормализация** | EBU R128 (`I=-14:TP=-1.5:LRA=9`) | Стандарт мобильного контента, не глушится алгоритмами |

## 4. Модули конвейера

1. **`tools/shorts_topics.py`:**
   - Реестр тем с текстом озвучки, таймингами хука, заголовком и хэштегами.
   - Тема №1 (Пилот): **"Тайна золотого диска Вояджера: что мы отправили пришельцам?"** (36 секунд).

2. **`tools/shorts_audio_engine.py`:**
   - Синтез речи через `edge-tts` с разбивкой по предложениям.
   - Генерация саундтрека:
     - 0.0–2.5с: Sub-bass Drop (45–90 Hz sweep)
     - 0.0–36.0с: Space Ambience Drone + тихие радио-клики телеметрии NASA
     - 12.0с, 24.0с: Cinematic Whoosh переходы
   - Нормализация в один проход через `ffmpeg loudnorm`.

3. **`tools/shorts_render_engine.py`:**
   - Генерация кадров 1080×1920 на NumPy + PIL.
   - Векторный рендер центрального объекта (Золотой Диск, Пульсарная карта, Земля, Зонд).
   - Отрисовка субтитров по точным миллисекундным меткам.
   - Стриминг кадров через pipe в `ffmpeg stdin`.

4. **`tools/shorts_cloud_runner.py`:**
   - CLI-скрипт для полного автономного прогона.
   - Загрузка в CDN `/opt/cyberdeck/public/`.
   - Отправка в Telegram `@prostov_shrink_bot`.
