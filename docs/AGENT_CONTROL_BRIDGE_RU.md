# Agent Control → видеодвижок

Экспортируйте задание из панели **Видеостудия → Задание (JSON)**.
Проверка:
```
python tools/agent_control_job_check.py путь/к/video-job-xxx.json
```
Валидатор проверяет формат, длительность, ориентацию кадра, сценарий, количество планов и запрет на ложные отметки успешного рендера.

**Важно:** JSON-контракт пока не запускает существующий движок автоматически. Движок требуется адаптировать: очереди задач, раскадровка/аудио/исходники, renderer, ffprobe/QA, ссылка на готовый MP4 и подтверждение публикации.

- `cloud-motion-studio`: текущие 5 фиксированных сцен и отсутствующие аудио-активы недостаточны для универсального фильма 2–4 минуты.
- `viralna-studio-ai`: обработка Shorts требует исходного видео, FFmpeg и установленной рабочей среды Windows.
- Секретные токены не сохраняйте в JSON и не коммитьте в GitHub.
- Отправку в Telegram включайте только после отзыва ранее опубликованного токена и настройки `TELEGRAM_BOT_TOKEN`/`TELEGRAM_CHAT_ID` в безопасном окружении.
